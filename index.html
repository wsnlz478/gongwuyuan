一、言语理解与表达 行测核心

题型概述

言语理解与表达是行测中题量最大、分值最高的模块之一，通常考查 30～40 题，建议用时 30～35 分钟。主要分为三大板块：逻辑填空、片段阅读、语句表达，部分事业单位还会考查病句辨析、歧义句、标点符号、修辞等基础知识。

  • 逻辑填空：考查语境分析与词语辨析，约 10～20 题。
  • 片段阅读：考查主旨概括、意图判断、细节理解等，约 15～20 题。
  • 语句表达：考查语句排序、语句填空、下文推断，约 5～10 题。
  • 基础知识（事业编）：病句、歧义句、标点、修辞、错别字、谦敬辞等。
重点总原则：先语境，后词语；材料为王，问什么答什么。逻辑填空切忌“读着顺口就选”，片段阅读切忌“过度脑补”。

知识点

（一）逻辑填空——五大语境关系

关系标志词方法
解释说明即、就是、也就是说、冒号、破折号横线处与提示信息语义相近
并列关系顿号、分号、和、及、与、同时同向并列语义相近，反向并列语义相反
转折关系但是、然而、却、其实、事实上前后语义相反或相对
递进关系不仅……而且、甚至、更、乃至后项程度、范围更进一层
因果关系因为……所以、因此、由于、导致由因推果或由果溯因，因果不能倒置

（二）实词辨析六大角度

角度说明典型例子
词义轻重程度由轻到重轻视 < 蔑视 < 鄙视
范围大小概念外延不同战争 > 战役 > 战斗
感情色彩褒义 / 中性 / 贬义成果（褒）/ 结果（中）/ 后果（贬）
搭配对象固定搭配习惯改善生活 / 改进方法
语义侧重侧重点不同鉴别（辨真假）/ 辨别（分好坏）
语体色彩口语 / 书面语爸爸（口语）/ 父亲（书面）

（三）高频易错成语速记

成语正确含义易错点
首当其冲最先受到攻击或遭遇灾难误作“冲在最前面”
差强人意大体上还能使人满意误作“不如人意”
万人空巷人们都从巷子里出来，形容轰动误作“街巷空无一人”
不刊之论不可修改的言论（形容精当）误作“不能刊登”
文不加点文章一气呵成，文思敏捷误作“不加标点”
屡试不爽屡次试验都没有差错误作“屡次尝试都不开心”
惨淡经营苦心谋划、艰苦创业误作“经营不善”
相敬如宾夫妻互相尊重，像对待宾客一样误用于朋友、同事
汗牛充栋书籍极多误用于其他物品

（四）片段阅读核心方法

  • 转折后是重点：但是、然而、其实、事实上。
  • 结论后是重点：因此、所以、可见、总之。
  • 递进后是重点：更、甚至、尤其。
  • 必要条件后是重点：只有……才；“应该、需要、必须”是对策。
  • 主题词：文段高频出现的名词，正确选项必须包含主题词。

（五）细节题六大陷阱

  • 无中生有：文段未提及的信息。
  • 偷换概念：换掉主体、客体或关键修饰语。
  • 偷换时态：已然 / 未然 / 正在进行混淆。
  • 偷换数量/范围：全部↔部分，可能↔必然。
  • 偷换逻辑：因果倒置、充分必要混淆。
  • 绝对表述：一定、必然、全部、完全、唯一、永远。

常规解题技巧

  1. 审题要慢：先看提问方式，判断题型。
  2. 找重点句：片段阅读中圈画关联词，锁定转折、结论、对策句。
  3. 抓主题词：正确选项必须包含主题词，不含主题词直接排除。
  4. 语境对应：逻辑填空先找横线处的呼应点，再辨析词语。
  5. 选项对比：不是找“对的”，而是找“最对的”。

秒杀技巧

高频主旨概括秒杀：“虽然A，但是B。因此C。”重点在C。
高频主题词秒杀：文段高频出现的名词就是主题词，不含主题词的选项直接排除。
高频意图题对策秒杀：文段是“问题+危害”结构，正确答案90%是针对问题的对策。
高频尾句核心秒杀：只看最后两句，正确选项基本是尾句的同义替换。
高频细节题绝对化排除：含“一定、必然、全部”的选项大概率错。

蒙题技巧

言语蒙题五法：
① 选中庸不选绝对：语气委婉的选项正确率更高。
② 选全面不选片面：主旨题中概括最全面的往往正确。
③ 选对策不选问题：意图题中，针对问题提对策的选项优先。
④ 选主题词不选无关词：不含主题词的直接排除。
⑤ 逻辑填空：不会就选“常见搭配”，读起来最顺的往往是答案。

真题例题

【例题1·主旨概括】近年来，我国城市轨道交通建设速度不断加快，运营里程持续增长，为市民出行带来了极大便利。然而，部分城市在规划建设中存在盲目攀比、贪大求全的倾向，导致线路利用率低、运营亏损严重。因此，城市轨道交通建设必须量力而行，与城市实际需求和财政承受能力相匹配。

这段文字意在说明：

A. 我国城市轨道交通建设成就显著

B. 城市轨道交通建设应量力而行

C. 部分城市轨道交通运营亏损严重

D. 城市轨道交通建设速度应放缓

【答案】B

【解析】文段结构为“背景引入—转折指出问题—因此得出结论”。“然而”后指出问题，“因此”后是结论句，即“城市轨道交通建设必须量力而行”，B项与之对应。

（2023年联考真题改编）

【例题2·细节理解】研究人员对2000名成年人进行了为期5年的跟踪调查，发现每天饮用3杯以上咖啡的人，患心血管疾病的风险比不饮用咖啡的人低约15%。研究人员指出，这可能与咖啡中的抗氧化物质有关，但这一结论仍需更大规模的实验证实。

根据这段文字，下列说法正确的是：

A. 咖啡中的抗氧化物质能预防心血管疾病

B. 每天喝3杯咖啡的人不会患心血管疾病

C. 该研究结论尚需进一步验证

D. 不喝咖啡的人患心血管疾病的风险更高

【答案】C

【解析】A项“能预防”将原文“可能有关”偷换为确定性表述；B项“不会患”绝对化；D项原文是“风险低约15%”，未说“不喝咖啡的人风险更高”；C项对应“仍需更大规模的实验证实”。

（2024年国考真题改编）

易错项

易错言语理解十大易错点：
① 逻辑填空选题干原词：横线处已有原词提示时，一般不选原词。
② 忽略感情色彩：褒贬误用是逻辑填空高频陷阱。
③ 成语望文生义：首当其冲、差强人意、万人空巷、文不加点等。
④ 成语对象误用：相敬如宾（夫妻）、汗牛充栋（书籍）、豆蔻年华（少女）。
⑤ 主旨题误选转折前内容：“然而”“但是”之前的内容往往是背景铺垫。
⑥ 意图题引申过泛：选项道理没错，但脱离了文段核心寓意。
⑦ 细节题被绝对化迷惑：“一定”“全部”“完全”“唯一”大概率错。
⑧ 排序题首句判断错误：含指代词、关联词后半段、举例句不能作首句。
⑨ 病句题忽略“两面对一面”：“能否”“是否”是两面，后文需对应两面。
⑩ 得体题谦敬辞混用：“惠赠”“笑纳”是敬辞用于对方，“家父”“拙作”是谦辞用于自己。

二、数量关系 拉分模块

题型概述

数量关系通常考查 10～15 题，是行测中难度最高、最拉分的模块。建议用时 10～15 分钟，放在最后做，先挑简单的、有思路的做，难题果断放弃。

  • 核心思想：代入排除、数字特性、赋值、方程、比例、十字交叉。
  • 高频题型：行程问题、工程问题、经济利润、排列组合与概率、最值问题、容斥原理。
  • 经典模型：牛吃草、鸡兔同笼、年龄问题、钟表问题、方阵、植树、空瓶换水、页码、比赛。
重点数量关系的本质：不是“算出来”，而是“选出来”。方法优先级：代入排除 > 数字特性 > 赋值 > 方程 > 比例。

知识点

（一）核心解题思想

方法适用题型核心动作
代入排除法多位数、年龄、余数、不定方程、选项信息充分从简单选项或中间选项开始代
数字特性法奇偶、倍数、尾数和差同性；倍数特性；尾数循环
赋值法工程、行程、利润、浓度赋总量为最小公倍数，赋效率为比例值
方程法和差倍比、经济利润、行程设所求量为x，列等量关系
比例法行程、工程路程一定，速度与时间成反比
十字交叉法混合平均、浓度混合、增长率混合部分量之比 = 差值反比

（二）数量关系完整公式大全

【一、基础运算】
平方差：a² − b² = (a+b)(a−b)
完全平方：(a±b)² = a² ± 2ab + b²
裂项相消：1/[n(n+1)] = 1/n − 1/(n+1)
凑整法：99×36 = (100−1)×36 = 3600−36 = 3564
【二、和差倍比】
和差问题：大数 = (和 + 差) ÷ 2，小数 = (和 − 差) ÷ 2
和倍问题：小数 = 和 ÷ (倍数 + 1)
差倍问题：小数 = 差 ÷ (倍数 − 1)
【三、平均数】
算术平均数 = 总数 ÷ 个数
调和平均数 = 2ab/(a+b)（等距离平均速度、等量混合）
十字交叉法：A/B = (混合值 − B值) / (A值 − 混合值)
【四、行程问题】
基本公式：路程 = 速度 × 时间（s = vt）
相遇问题：路程和 = 速度和 × 相遇时间
追及问题：路程差 = 速度差 × 追及时间
流水行船：顺水速度 = 船速 + 水速；逆水速度 = 船速 − 水速
船速 = (顺水 + 逆水) ÷ 2；水速 = (顺水 − 逆水) ÷ 2
火车过桥：完全过桥路程 = 桥长 + 车长；完全在桥上 = 桥长 − 车长
错车：路程和 = 两车车长之和
环形跑道：同向追及（多跑一圈），反向相遇（合跑一圈）
等距离平均速度：v平均 = 2v₁v₂ / (v₁ + v₂)
【五、工程问题】
工作总量 = 工作效率 × 工作时间
赋值技巧：已知时间 → 赋总量为时间的最小公倍数；已知效率比 → 直接赋效率为比例值
交替工作：先算一个循环的工作量，再算剩余量，注意最后一步是谁在做
【六、经济利润】
利润 = 售价 − 成本
利润率 = 利润 ÷ 成本 × 100%
售价 = 成本 × (1 + 利润率)
打折：打n折 = 售价 × n/10
分段计费：不同阶段收费标准不同，分开计算
利润最值：总利润 = 单件利润 × 销量，用二次函数求最值
【七、浓度问题】
浓度 = 溶质 ÷ 溶液 × 100%
溶质 = 溶液 × 浓度
混合前后溶质总量不变
蒸发：溶质不变，溶液减少；加水：溶质不变，溶液增加
【八、排列组合】
分类用加法，分步用乘法
排列（有序）：A(n,m) = n!/(n−m)!
组合（无序）：C(n,m) = n!/[m!(n−m)!]
捆绑法：要求某些元素必须相邻，捆成一个整体
插空法：要求某些元素不能相邻，先排其他元素，再插空
隔板法：n个相同元素分给m个人，每人至少1个，方法数 = C(n−1, m−1)
错位排列：D₁=0，D₂=1，D₃=2，D₄=9，D₅=44，D₆=265
环形排列：n人围成一圈，方法数 = (n−1)!
【九、概率问题】
概率 = 满足条件的情况数 ÷ 总情况数
独立事件：P(AB) = P(A)·P(B)
互斥事件：P(A+B) = P(A)+P(B)
对立事件：P(A) = 1 − P(非A)
【十、几何问题】
三角形面积 = 底 × 高 ÷ 2
圆面积 = πr²，周长 = 2πr
矩形面积 = 长 × 宽，周长 = 2(长+宽)
梯形面积 = (上底+下底) × 高 ÷ 2
正方体体积 = a³，表面积 = 6a²
圆柱体积 = πr²h
相似图形：边长比 = k，面积比 = k²，体积比 = k³
【十一、容斥原理】
两集合：A∪B = A + B − A∩B
总数 = A + B − 两者都 + 两者都不
三集合标准型：A∪B∪C = A+B+C − AB − AC − BC + ABC
三集合非标准型：A+B+C − 只满足两个 − 2×满足三个 = 总数 − 都不
【十二、最值问题】
抽屉原理（最不利原则）：“至少……才能保证……”→ 最不利情况 + 1
数列构造：求“排名第几的最多/最少是多少”，构造其他项为极端值
多集合反向：总人数 − 不满足条件的人数之和
【十三、等差数列】
通项：aₙ = a₁ + (n−1)d
求和：Sₙ = n(a₁+aₙ)/2 = na₁ + n(n−1)d/2
【十四、等比数列】
通项：aₙ = a₁·q^(n−1)
求和：Sₙ = a₁(1−qⁿ)/(1−q)（q≠1）
【十五、余数问题】
同余定理：若 a ≡ b (mod m)，c ≡ d (mod m)，则 a+c ≡ b+d，a×c ≡ b×d (mod m)
中国剩余定理（韩信点兵）：“余同取余，和同加和，差同减差，最小公倍数做周期”
【十六、周期问题】
找最小循环周期 T，用总数 ÷ T 看余数，余几就是周期中的第几个
【十七、年龄问题】
核心：年龄差不变；过n年，每人长n岁；年龄倍数随时间变化
【十八、钟表问题】
分针速度：6°/分钟；时针速度：0.5°/分钟；速度差：5.5°/分钟
追及公式：时间 = 角度差 ÷ 5.5
【十九、牛吃草问题】
核心公式：原有草量 = (牛数 − 每天生长量) × 天数
设每头牛每天吃1份草：(N₁ − x) × T₁ = (N₂ − x) × T₂
【二十、鸡兔同笼】
假设法：兔数 = (总脚数 − 2×总头数) ÷ 2
【二十一、日期问题】
平年365天 = 52周 + 1天；闰年366天 = 52周 + 2天
闰年判断：能被4整除但不能被100整除，或能被400整除
大月（31天）：1、3、5、7、8、10、12；小月（30天）：4、6、9、11
2月：平年28天，闰年29天
【二十二、方阵问题】
实心方阵：总人数 = n²（n为每边人数）
最外层人数 = 4n − 4 = 4(n−1)；相邻两层人数差 = 8
【二十三、植树问题】
不封闭路线两端都种：棵数 = 段数 + 1 = 总长÷间距 + 1
不封闭路线只种一端：棵数 = 段数
不封闭路线两端都不种：棵数 = 段数 − 1
封闭路线（圆形）：棵数 = 段数
【二十四、空瓶换水】
n个空瓶换1瓶水，相当于n−1个空瓶“免费”喝1瓶水
最多喝到的水 = 初始购买瓶数 + 初始购买瓶数 ÷ (n−1)（取整）
【二十五、页码问题】
1～9页：每页1个数字，共9个
10～99页：每页2个数字，共90×2 = 180个
100～999页：每页3个数字，共900×3 = 2700个
【二十六、比赛问题】
单循环赛：n个队，比赛场数 = C(n,2) = n(n−1)/2
双循环赛：比赛场数 = n(n−1)
淘汰赛：决出冠军需 n−1 场

常规解题技巧

  1. 先扫全卷，挑软柿子：先做工程、利润、容斥、和差倍比等套路清晰的题。
  2. 能代入就代入：选项信息充分的题，优先代入排除。
  3. 能赋值就赋值：没有具体数值的题，大胆赋值。
  4. 善用数字特性：奇偶、倍数、尾数快速排除错误选项。
  5. 学会放弃：单题超过2分钟无思路，立即跳过。

秒杀技巧

高频代入排除法：年龄、多位数、不定方程，直接代入选项验证。
高频倍数特性：题目出现分数、比例、百分数，优先看倍数。
高频奇偶特性：三奇一偶选偶数，三偶一奇选奇数。
高频工程赋值：赋总量为时间的最小公倍数。
高频极值秒杀：问“最大”优先选第二大，问“最小”优先选第二小。

蒙题技巧

数量蒙题六法：
① 选项中有明显倍数关系的，选倍数。
② 选项中有两个数相加等于第三个数，答案往往在其中。
③ 问最大选次大，问最小选次小。
④ 几何题不会，选带根号的或带π的。
⑤ 行程题不会，选中间值。
⑥ 实在不会，统一蒙B或C。

真题例题

【例题1·工程问题】甲单独完成一项工程需10天，乙单独完成需15天。两人合作需多少天？

A. 5　　B. 6　　C. 7　　D. 8

【答案】B

【解析】赋总量为30（10和15的最小公倍数）。甲效率3，乙效率2，合作效率5。时间 = 30÷5 = 6天。选B。

（2023年事业单位联考真题）

【例题2·年龄问题】10年前爸爸的年龄是儿子年龄的7倍，15年后，爸爸的年龄是儿子的2倍。则现在爸爸的年龄是多少岁？

A. 35　　B. 45　　C. 60　　D. 55

【答案】B

【解析】设儿子10年前年龄是x，则爸爸10年前年龄是7x，年龄差为6x。15年后，儿子年龄为x+25，爸爸年龄为7x+25，年龄差还是6x，且爸爸年龄是儿子的2倍，说明年龄差等于儿子的年龄，即6x = x+25，解得x=5。所以爸爸现在的年龄是7×5+10=45岁。

（2025年联考真题）

易错项

易错数量关系十大易错点：
① 等距离平均速度误用算术平均：必须用调和平均数 2v₁v₂/(v₁+v₂)。
② 火车过桥漏加车长：完全过桥路程 = 桥长 + 车长。
③ 工程交替工作算错最后一步：注意最后一步是谁在做。
④ 利润率与折扣混淆：利润率基于成本，折扣基于售价。
⑤ 排列组合“至少”“至多”忘记用对立事件减法。
⑥ 隔板法忘记“每人至少一个”的前提条件。
⑦ 容斥原理三集合公式中加减项记错。
⑧ 抽屉原理“最不利”忘记最后+1。
⑨ 牛吃草问题忘记草在生长。
⑩ 日期问题中闰年2月29天被忽略。

三、判断推理 技巧为王

题型概述

判断推理通常考查 30～40 题，是行测中技巧性最强、最容易拿满分的模块。建议用时 30～35 分钟。分为四大板块：图形推理、定义判断、类比推理、逻辑判断。

  • 图形推理：位置、样式、属性、数量、空间重构、特殊规律。
  • 定义判断：关键词法（主体、客体、方式、目的、原因、结果、条件）。
  • 类比推理：语义关系、逻辑关系、语法关系。
  • 逻辑判断：翻译推理、真假推理、分析推理、加强削弱、原因解释、日常结论。

常规解题技巧

  1. 图形推理：先宏观后微观，先属性后数量，30秒无思路果断猜。

  3. 类比推理：先横向找关系，再纵向比选项，注意二级辨析。
  4. 翻译推理：熟记“如果就前推后，只有才后推前”，逆否等价是王道。
  5. 加强削弱：找论点论据，搭桥/拆桥最强，另有他因次之。

秒杀技巧

高频一笔画秒杀：出现“五角星、切圆、日字变形、田字变形、多端点图形”，优先考虑一笔画。
高频加强论证搭桥秒杀：问“前提、假设”，优先选同时包含论点、论据核心关键词的搭桥选项。
高频类比推理造句秒杀：题干造句子，原封不动套到选项上，通顺的就是正确答案。
高频六面体相对面秒杀：相对面不能同时出现，直接排除不符合的选项。

蒙题技巧

判断推理蒙题四法：
① 图形推理：30秒无思路直接蒙，优先选“对称”或“规整”的选项。
② 定义判断：选项三同一异，优先选那个不一样的；选“最符合常理”的选项。
③ 类比推理：选与题干词性一致、关系最接近的；不会就选“顺序一致”的选项。
④ 逻辑判断：削弱题选“切断论据与论点联系”的选项；加强题选“建立论据与论点联系”的选项。

真题例题

【例题1·加强论证】论据：某公司的员工都喜欢吃辣，论点：该公司的员工都身体健康。以下哪项是上述论证的前提？

A. 喜欢吃辣的人都身体健康

B. 身体健康的人都喜欢吃辣

C. 该公司的员工都很年轻

D. 吃辣可以提升身体的免疫力

【答案】A

【解析】搭桥就是把论据的“喜欢吃辣”和论点的“身体健康”联系起来，A选项刚好建立了二者的联系，直接秒选A。

（2023年国考真题改编）

【例题2·削弱论证】研究发现，经常喝咖啡的人患心脏病的概率比不喝咖啡的人低。因此，喝咖啡能预防心脏病。以下哪项如果为真，最能削弱上述结论？

A. 咖啡中含有抗氧化物质，对心脏有益

B. 经常喝咖啡的人往往也注重锻炼和饮食

C. 有些人喝咖啡后心跳加速

D. 不喝咖啡的人中也有长寿的

【答案】B

【解析】题干结论：喝咖啡→预防心脏病。B项提出“经常喝咖啡的人往往也注重锻炼和饮食”，说明可能是锻炼和饮食降低了心脏病风险，而非咖啡，属于“另有他因”削弱。

（2024年省考真题改编）

易错项

易错判断推理十大易错点：
① 一笔画奇点数数错：端点不算交点；奇点是指引出奇数条线的点。
② 六面体相对面与相邻面混淆：展开图中相隔一个面的两个面是相对面。
③ 定义判断忽略“主体”和“客体”：只看行为，不看谁做的、对谁做的。
④ 类比推理“种属”与“组成”混淆：苹果是水果（种属），轮胎是汽车（组成）。
⑤ 翻译推理“只有……才”翻译方向弄反：“只有A才B”翻译为 B→A。
⑥ 逆命题与否命题误认为等价于原命题：只有逆否命题才等价。
⑦ 真假推理中“所有是”与“有的是”不是矛盾关系：“所有是”的矛盾是“有的不是”。
⑧ 分析推理条件不足时强行选“唯一”：注意“无法确定”也是选项。
⑨ 加强削弱中“另有他因”与“否定论据”力度混淆。
⑩ 原因解释中否定矛盾双方之一：解释要能包容矛盾双方。

四、资料分析 拿分王牌

题型概述

资料分析通常考查 20 题，是行测中唯一可以拿满分的模块。建议用时 20～25 分钟，放在靠前位置做。

  • 核心考点：基期量、现期量、增长率、增长量、比重、平均数、倍数、指数、拉动增长、贡献率。
  • 速算技巧：截位直除、分数比较、特征数字、错位加减。
  • 常见陷阱：时间、单位、范围、概念、百分点、年均增长。
重点资料分析第一关：分清“现期”与“基期”。基期是“比”字后面的时间，现期是“比”字前面的时间。

知识点

（一）核心公式速查

增长率：r = (现期 − 基期) ÷ 基期 = 现期÷基期 − 1
基期量：基期 = 现期 ÷ (1 + r)
增长量：增长量 = 现期 ÷ (1+r) × r
间隔增长率：R = r₁ + r₂ + r₁r₂
年均增长率：(现期/基期)^(1/n) − 1
比重：比重 = 部分 ÷ 整体
基期比重：现期比重 × (1+整体增长率) ÷ (1+部分增长率)
比重变化：部分增速 > 整体增速 → 比重上升
平均数增长率：(a − b) ÷ (1 + b) ≈ a − b
倍数：A是B的n倍：n = A÷B；A比B多n倍：A = B×(n+1)
指数：增长率 = (指数 − 100) ÷ 100
拉动增长：部分增长量 ÷ 整体基期量 × 100%
贡献率：部分增长量 ÷ 整体增长量 × 100%

（二）百化分表格（必须背）

1/2=50%1/3≈33.3%1/4=25%1/5=20%1/6≈16.7%
1/7≈14.3%1/8=12.5%1/9≈11.1%1/10=10%1/11≈9.1%
1/12≈8.3%1/13≈7.7%1/14≈7.1%1/15≈6.7%1/16=6.25%
1/17≈5.9%1/18≈5.6%1/19≈5.3%1/20=5%

（三）常见陷阱

陷阱类型说明
时间陷阱同比/环比混淆；基期现期看错
单位陷阱亿元/万元/元；吨/万吨；%与‰
范围陷阱全国/全省/全市；部分/整体
概念陷阱增长率/增长量；倍数/多几倍
百分点陷阱%与百分点混用
年均增长陷阱年份差算错（间隔年数）

常规解题技巧

  1. 先看问题，再找数据：明确问什么，避免无效阅读。
  2. 列式要快，计算要准：熟记公式，截位直除。
  3. 注意单位与时间：亿元/万元、同比/环比、基期/现期。
  4. 善用排除法：选项差距大时大胆估算。
  5. 不纠结难题：单题超过2分钟先跳过。

秒杀技巧

高频截位直除：选项差距大截2位，差距小截3位；一步除法只截分母。
高频两期比重升降秒杀：a>b比重上升，a<b下降；差值一般选最小。
高频增长量比较口诀：大大则大，一大一小看乘积（现期×r）。
高频混合增长率：整体增速介于两者之间，偏向基数大一方。
高频百化分秒杀增长量：r=1/n，增长量=现期/(n+1)。

蒙题技巧

资料蒙题五法：
① 综合分析题优先看C、D选项，先验证简单选项。
② 两期比重变化：没时间计算直接选最小选项。
③ 选项出现量级差异，优先看单位，排除量级错误。
④ 时间不够，优先选和估算结果最接近的。
⑤ 增长率题：不会就选“中间值”。

真题例题

【例题1·比重变化】2022年，某省的GDP增长了6%，其中第一产业的增加值增长了4%，问2022年第一产业增加值占GDP的比重比上年：

A. 上升了2个百分点　　B. 下降了2个百分点

C. 上升了0.2个百分点　　D. 下降了0.2个百分点

【答案】D

【解析】部分增长率a=4%，整体增长率b=6%，a<b，所以比重下降，排除A、C，然后直接选小的那个0.2，秒选D。

（2023年国考真题）

【例题2·间隔增长率】2025年某省GDP同比增长8%，2024年同比增长5%，问2025年相对2023年的增长率是多少？

A. 13%　　B. 13.4%　　C. 14%　　D. 15%

【答案】B

【解析】间隔增长率 r = r₁ + r₂ + r₁r₂ = 8% + 5% + 8%×5% = 13.4%。选B。

（2025年事业单位联考真题）

易错项

易错资料分析十大易错点：
① 同比与环比混淆：同比是与去年同期比，环比是与上一个统计周期比。
② 增长量公式用错：增长量 = 现期÷(1+r)×r，不是现期×r。
③ 间隔增长率忘记加r₁×r₂。
④ 混合增长率直接取平均：整体增长率介于部分之间，偏向基期大者。
⑤ 年均增长率年份差算错：间隔年数 = 末年 − 初年。
⑥ 比重变化用“%”而非“百分点”。
⑦ 基期比重公式记反。
⑧ 平均数增长率忘记除以(1+b)。
⑨ “是几倍”与“多几倍”混淆：“是2倍”= A=B×2；“多2倍”= A=B×3。
⑩ 指数与增长率换算错误：指数105对应增长5%。

五、常识判断 积累为王

题型概述

常识判断通常考查 20 题，建议用时 8～10 分钟，放在最前面或最后面快速作答，不纠结。考查范围极广，包括政治、法律、经济、科技、人文、地理、管理公文等。

  • 政治：马原、毛概、中特、习思想、党史、时政。
  • 法律：宪法、民法、刑法、行政法、劳动法、消法。
  • 经济：微观、宏观、财政政策、货币政策、国际经济。
  • 科技：物理、化学、生物、高新科技。
  • 人文：中国古代史、近现代史、文学文化。
  • 地理：自然地理、人文地理、中国之最。
  • 管理公文：行政管理、15种法定公文文种。
重点常识复习策略：抓大放小，重点复习政治、法律、科技；时政必看近一年重大会议、讲话、政策、科技成就。

知识点

（一）政治核心考点

  • 社会主要矛盾：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。
  • 五位一体：经济、政治、文化、社会、生态文明建设。
  • 四个全面：全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党。
  • 新发展理念：创新、协调、绿色、开放、共享。
  • 两个确立、两个维护。

（二）法律核心考点

法律核心考点
宪法国体、政体、国家机构、公民权利与义务
民法民事行为能力（8/18周岁）、诉讼时效（3年/20年）、继承顺序
刑法刑事责任年龄（12/14/16周岁）、正当防卫、紧急避险
行政法行政处罚种类、行政复议、行政诉讼
劳动法试用期、加班工资、劳动争议

（三）经济核心考点

类型措施适用
积极（扩张）财政政策增加政府支出、减税、增发国债经济衰退、通货紧缩
紧缩财政政策减少政府支出、增税、减少国债经济过热、通货膨胀
宽松货币政策降低存款准备金率、降低利率、买入国债经济衰退
紧缩货币政策提高存款准备金率、提高利率、卖出国债通货膨胀
易错财政政策主体是政府；货币政策主体是央行。存款准备金率属于货币政策，不是财政政策。

（四）科技核心考点

  • 光现象：直线传播（影子）、反射（倒影）、折射（筷子变弯）、色散（彩虹）。
  • 航天成就：神舟系列、天宫空间站、嫦娥探月、天问探火、北斗导航。
  • 深海探测：“蛟龙号”“奋斗者号”载人潜水器。
  • 量子科技：量子通信、量子计算、量子纠缠。

（五）人文核心考点

  • 四书：《大学》《中庸》《论语》《孟子》。
  • 五经：《诗》《书》《礼》《易》《春秋》。
  • 唐宋八大家：韩愈、柳宗元、欧阳修、苏洵、苏轼、苏辙、王安石、曾巩。
  • 四大发明：造纸术、印刷术、指南针、火药。

常规解题技巧

  1. 排除法为王：先划掉明显错误项。
  2. 关键词法：抓题干关键词，对应相关知识点。
  3. 联想法：由题干联想到相关历史、法律、科技知识。
  4. 时政题：近一年重大会议、讲话、政策优先。

秒杀技巧

高频语气中庸秒杀：优先选含“可能、也许、大概、一定程度上、逐步、有待”等温和表述的选项。
高频民族自豪感秒杀：优先选体现中国正面发展、科技突破、大国担当的选项。
高频法律题弱势群体秒杀：法律题的正确选项，一定是保护弱势群体的。

蒙题技巧

常识蒙题六法：
① 选“正能量”的选项。
② 选“符合国家政策方向”的选项。
③ 法律题：选“保护弱者”的选项。
④ 科技题：选“常见、基础”的选项。
⑤ 历史题：选“时间、人物、事件对应正确”的选项。
⑥ 绝对化表述（一定、全部、唯一）大概率错。

真题例题

【例题1·时政】关于粮食安全，下列说法正确的是：

A. 以进口为主保障粮食供给

B. 牢牢守住18亿亩耕地红线

C. 可以永久占用基本农田开发项目

D. 粮食安全不属于国家安全范畴

【答案】B

【解析】我国坚持谷物基本自给、口粮绝对安全；严守18亿亩耕地红线；基本农田严禁违规占用；粮食安全是国家安全重要部分。选B。

（2024年国考真题）

【例题2·法律】根据《民法典》，下列属于无民事行为能力人的是：

A. 7岁的小明　　B. 15岁的小红　　C. 17岁的小刚　　D. 18岁的小李

【答案】A

【解析】不满8周岁的未成年人为无民事行为能力人。A项7岁符合。B、C为限制民事行为能力人，D为完全民事行为能力人。

（2023年事业单位联考真题）

易错项

易错常识判断十大易错点：
① 社会主要矛盾表述记错：不是“物质文化需要”。
② 毛泽东思想活的灵魂与三大法宝混淆。
③ 刑事责任年龄节点记错：12、14、16周岁是关键节点。
④ 行政处罚与刑罚混淆：拘役是刑罚。
⑤ 财政政策与货币政策主体混淆。
⑥ 通货膨胀时政策方向选反：应采取紧缩政策。
⑦ 人民币升值有利于进口而非出口。
⑧ 光的反射、折射、直线传播混淆。
⑨ “四书”与“五经”内容记混。
⑩ 公文文种适用范围记错。

六、申论 材料为王

题型概述

申论是公务员考试的核心科目，考试时间国考180分钟、多数省考150分钟，满分100分。国考5题，省考4题。五大题型：归纳概括、综合分析、提出对策、贯彻执行、申发论述。

  • 小题评分：按点给分，每个要点2～5分，多写不扣分，少写扣分。
  • 作文评分：按档给分，一类文立意深刻、结构严谨、论证充分。
  • 答案来源：90%来自材料，10%靠自身积累。
重点申论本质：模拟公务员日常工作。所有答案要点都来自材料，脱离材料=脱离得分点。核心原则：材料为王、问什么答什么、要点全面、条理清晰。

知识点

（一）阅读材料的三大方法

关键词类型常见标志词作用
问题词问题、困难、瓶颈、不足、缺失、滞后、矛盾找问题
原因词因为、由于、原因在于、根源在于、究其原因找原因
影响词有利于、促进了、推动了、导致了、危害了找影响
对策词应该、需要、必须、建议、措施、要、应找对策
观点词指出、强调、认为、表示、显示找观点
关联词但是、然而、因此、所以、同时、此外理逻辑

（二）五大题型速查

题型核心方法答题结构分值
归纳概括找点→加工→分类总括句+分条要点10～20分
综合分析解释/评价/启示亮观点+分析+结论15～25分
提出对策问题反推+经验借鉴总括句+分条对策15～25分
贯彻执行审题+格式+内容标题+称谓+正文+落款15～25分
申发论述立意+结构+论证开头+分论点+结尾40分

（三）常见公文文种格式

文种格式内容要点
讲话稿标题+称谓+正文开场白+主体+结束语
倡议书标题+称谓+正文+落款背景+倡议内容+呼吁
汇报材料标题+正文背景+做法+成效+问题+计划
建议书标题+称谓+正文+落款背景+建议内容+希望
短评标题+正文观点+分析+结论

常规解题技巧

  1. 审题要慢：至少花2分钟审清作答对象、范围、要求。
  2. 找点要全：逐段阅读，不遗漏任何可能要点。
  3. 加工要精：合并同类项，提炼关键词。
  4. 书写要快：字迹工整，分条作答，不涂改。
  5. 作文要稳：立意准确第一，结构完整第二，文采第三。

秒杀技巧

高频综合分析万能公式：是什么—为什么—怎么办。
高频对策五大维度：①思想宣传 ②制度机制 ③硬件设施 ④监管执法 ⑤资金人才。
高频公文格式保底：哪怕内容看不懂，标题、称谓、落款格式分一定要拿满。
高频作文五段三分：开头150字 + 分论点1（250字）+ 分论点2（250字）+ 分论点3（250字）+ 结尾100字。

蒙题技巧

申论兜底策略：
① 概括题：按“思想、制度、设施、人员、监管、资金”六大维度反向推导要点。
② 对策题：直接套用万能对策五维度填充。
③ 综合分析：强行套“是什么—为什么—怎么办”三段框架。
④ 公文题：格式分必须拿满，内容从材料中摘抄提炼。
⑤ 大作文：从题干和材料高频词提炼总论点。

真题例题

【例题1·归纳概括】根据给定材料，概括当前我国农村电商发展面临的主要问题。（15分）要求：全面准确、条理清晰，不超过200字。

【参考答案】

当前农村电商发展面临以下问题：一是基础设施薄弱。物流网络不健全，冷链设施缺乏，配送成本高。二是人才短缺。缺乏电商运营人才，农民网络技能不足。三是品牌意识弱。农产品标准化程度低，缺乏品牌打造。四是资金不足。融资渠道少，前期投入大。

（2023年省考真题改编）

【例题2·提出对策】针对当前农村环境污染问题，请提出解决对策。（20分）要求：措施具体可行、针对性强，不超过350字。

【参考答案】

针对农村环境污染问题，提出以下对策：一、加强宣传教育。通过村广播、宣传栏、村民大会等方式，普及环保知识，提高村民环保意识。二、完善基础设施。建设垃圾收集点和污水处理设施，推行垃圾分类和集中处理。三、强化制度保障。制定村规民约，明确环保责任，建立奖惩机制。四、加大资金投入。争取上级财政支持，引入社会资本参与农村环境治理。五、加强监管执法。建立日常巡查制度，对污染行为依法处罚。

（2024年省考真题改编）

易错项

易错申论十大易错点：
① 直接摘抄大段原文：不提炼概括，照抄材料原句。
② 要点杂乱不分条：不分段、不分条，阅卷人找不到采分点。
③ 对策太空泛：只写“加强管理”，不具体。
④ 公文格式写错：标题、称谓、落款位置错误。
⑤ 作文跑题偏题：立意脱离材料主题。
⑥ 字数严重不足/超标。
⑦ 脱离材料主观发挥。
⑧ 身份错位：使用超出基层权限的表述。
⑨ 综合分析只解释不分析。
⑩ 分论点脱离中心论点。

七、综合应用能力 事业编专属

题型概述

综合应用能力是事业单位联考的核心科目，按岗位性质分为A、B、C、D、E五类。考试时间120分钟，满分150分，全部为主观性试题。

类别适用岗位核心能力典型题型
A类综合管理岗管理角色意识、分析判断、计划控制、沟通协调、文字表达归纳概括、提出对策、应急处理、沟通协调、公文写作
B类社科专技岗阅读理解、逻辑思维、综合分析、文字表达概念分析、校阅改错、论证评价、材料分析、文章写作
C类自科专技岗阅读理解、逻辑思维、数据加工、文字表达科技文献阅读、科技实务、论证评价、材料作文
重点综A核心：材料为王、踩点给分；无客观选择题，全部为主观作答。文采不重要，关键词最重要。

知识点

（一）A类案例分析四大基础题型

题型题干识别词答题框架
概括类概括、归纳、梳理、总结、简述划关键词→合并同类项→分条整理
提出对策提出对策、解决措施、建议、方案问题反推+经验借鉴+实务操作
沟通协调劝说、沟通、安抚、调解共情安抚→倾听诉求→解释沟通→解决承诺
应急处置处理、处置、解决现场矛盾、接待投诉控制现场→调查核实→分类处置→善后长效

（二）公文写作通用格式

标题：关于+事由+的+文种（居中）
称谓：顶格写，后加冒号
正文：开头（背景/目的）+ 主体（核心内容）+ 结尾（总结/呼吁）
落款：发文机关 + 发文日期（右下角）
注意：讲话稿、汇报不需要落款；短评、新闻稿不需要称谓。

（三）B类校阅改错六大错误类型

错误类型具体表现
错别字错字、别字
用词不当近义词误用、成语误用、关联词误用

（四）B/C类论证评价常见错误

  • 偷换概念、以偏概全、绝对化表述、预期论据、强加因果、诉诸权威、非黑即白、类比不当。

常规解题技巧

  1. 先看题干，带着问题读材料：圈画关键词，不要盲目通读全文。
  2. 材料口语→机关规范词转换：如“没人管”→“监管缺位”。
  3. 答案尽量全部来源于材料。
  4. 答案分条，序号用1.2.3。
  5. 控制字数：严格按照题干字数，宁少勿多。

秒杀技巧

高频“节点+表述”格式：先写概括性节点（小标题），再用简洁语言展开表述。
高频应急处理万能逻辑：控制现场→调查核实→分类处置→善后长效。
高频沟通协调四步：拉近距离（动情）→阐述利害（晓理）→提出方案→达成共识。
高频公文写作凭事断：开头写背景缘由（凭），主体写核心内容（事），结尾写总结呼吁（断）。

蒙题技巧

综应兜底策略：
① 概括题：按“思想、制度、设施、人员、监管、资金”六大维度反向推导要点。
② 对策题：直接套用万能对策五维度填充。
③ 沟通应急题：固定四步框架，把材料信息填充进框架。
④ 公文题：哪怕内容看不懂，格式分一定要拿满。

真题例题

【例题1·A类提出对策】针对活动中存在的问题提出改进建议。（35分）要求：措施具体可行，针对性强，不超过400字。

【答题思路】① 先梳理材料中反映的问题（如“宣传不到位”“人员不足”“流程繁琐”）。② 逐一对应提出对策：宣传不到位→多渠道宣传、制作宣传手册；人员不足→招募志愿者、开展培训；流程繁琐→简化审批环节、推行线上办理。③ 按“节点+表述”书写。

【例题2·A类沟通协调】你是未成年人保护中心综合办公室工作人员，同事小王在工作中存在疏忽，导致服务对象信息登记不完整。请列出你与小王沟通的内容要点。（35分）

⚡ 秒杀与蒙题总口诀

一、总原则

重点秒杀不是玄学，而是“用规律代替计算，用排除代替求解”。蒙题不是瞎猜，而是“在信息不足时，利用命题人心理和选项分布规律，提高正确概率”。能秒则秒，不能秒则排，排不掉则蒙，蒙完不回头。

二、各模块秒杀要点

模块秒杀要点
言语理解转折递进后是重点；主题词必含；意图题选对策；细节题绝对化排除
数量关系代入排除、数字特性、赋值法、十字交叉、极值选次大/次小
判断推理一笔画、搭桥拆桥、类比造句、六面体相对面
资料分析截位直除、两期比重升降、增长量大大则大、混合增长率偏向大基期
常识判断语气中庸、民族自豪感、法律保护弱者、绝对化排除
申论综合分析“是什么—为什么—怎么办”；对策五大维度；公文格式保底
综应“节点+表述”；应急四步；沟通四步；公文凭事断

三、终极蒙题口诀

言语选中庸，数量选中间；
图形选对称，定义选常理；
类比选顺序，逻辑选逆否；
资料选接近，常识选正能。
实在不会做，统一蒙 B C。

四、考场策略

  1. 先易后难：先做自己擅长的板块，保证基础分。
  2. 果断放弃：单题超过2分钟无思路，立即跳过。
  3. 涂卡同步：做完一个板块涂一个板块，避免最后慌乱。
  4. 蒙题不回头：蒙完就过，不要反复改。
  5. 心态平稳：蒙题也是能力，不要因为不会而慌乱。
